## Publicar no GitHub Pages
Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para o repositório. Em Settings > Pages, selecione a branch principal e a pasta `/ (root)`.

Observação: as imagens foram extraídas das páginas do PDF para compor as galerias. O site não utiliza dependências de framework; as fontes externas carregam pelo Google Fonts.
